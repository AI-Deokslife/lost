# 학교 분실물 센터

습득 → 촬영·등록 → 학생 열람 → "내 것 같아요" 신청 → 본인 확인 후 수령 → 보관 기한 만료 처리

Cloudflare 무료 요금제로 운영됩니다. 결제 수단 등록도 필요 없습니다.

---

## 설치하기 (처음 한 번, 약 10분)

### 준비물
- **Cloudflare 계정**: https://dash.cloudflare.com/sign-up 에서 이메일로 가입 (무료)
- **Node.js**: https://nodejs.org 에서 **LTS** 버튼을 눌러 받은 뒤 "다음"만 눌러 설치

### 1단계. 압축 풀기
받은 `lost-and-found.zip`을 바탕화면 등에 압축 해제합니다.

### 2단계. 명령 창 열기
- **윈도우**: 압축을 푼 `lost-and-found` 폴더를 연 뒤, 위쪽 **주소창**을 클릭하고 `cmd`를 입력한 다음 엔터를 누릅니다.
- **맥**: Finder에서 `lost-and-found` 폴더를 오른쪽 클릭하고 **서비스 → 폴더에서 새로운 터미널 열기**를 고릅니다.

### 3단계. 설치 명령 입력
검은 창에 아래 한 줄을 입력하고 엔터를 누릅니다.

```
npm run setup
```

그다음은 화면 안내를 따라가면 됩니다.

1. 브라우저가 열리면 Cloudflare에 로그인하고 **Allow(허용)** 를 누릅니다.
2. 질문 3개에 답합니다.
   - 학교 이름 (예: `한빛고등학교`)
   - 학생 입장 코드 (예: `hanbit2026`) — 학생들에게 알려 줄 코드
   - 관리자 비밀번호 (8자 이상) — 학생부 선생님만 알고 있을 비밀번호
3. 처음 배포할 때 `workers.dev` 하위 도메인을 정하라고 하면 원하는 영어 이름을 입력합니다. 학교 영문 약칭 등이면 됩니다.
4. 마지막에 `https://lost-and-found.○○○.workers.dev` 주소가 나오면 설치가 끝난 것입니다.

## 사용하기

| 누가 | 어디로 | 들어가는 방법 |
|---|---|---|
| 학생 | 사이트 주소 | 입장 코드 입력 |
| 학생부 | 같은 주소 | 관리자 비밀번호 입력 → 관리 화면으로 자동 이동 |
| 조회·복도 TV | 주소 뒤에 `/today` | 관리자 비밀번호로 한 번 로그인해 두기 (물건이 많으면 10초마다 자동으로 넘어가요) |

**학생 화면**
- 사진 갤러리, 검색, 품목·장소·색상·기간 필터
- 물건을 누르면 상세 정보 → "내 것 같아요" 신청
- 분실 신고: 비슷한 물건이 들어오면 '내 신청' 탭에 "비슷한 물건이 들어왔어요!"가 자동으로 떠요

**학생부 화면**
- 등록: 사진 찍기 → 드래그로 모자이크 → AI로 채우기 → 등록 (등록번호 자동, 비슷한 분실 신고가 있으면 알려 줌)
- 물품 · 수령 신청 · 분실 신고 매칭 · 처리 대상(일괄 기부/폐기) · 통계
- **설정**: 학교 이름, 보관 기한, 장소 목록, 학생 입장 코드, 관리자 비밀번호를 화면에서 바로 변경
- **도구**: QR 포스터(A4 인쇄), 엑셀 내려받기, TV 화면, 사용설명서(PDF) 내려받기

**학생 직접 등록 (교무실 QR) — 선생님 입력 부담 줄이기**
1. 관리 화면 → 설정 → **학생 직접 등록**에서 켜고, **등록용 QR 포스터**를 인쇄해 교무실 책상에 세워 두세요.
2. 물건을 주운 학생이 QR을 찍으면 비밀번호 없이 등록 화면이 열려요. 사진·품목·장소·학번·이름을 입력하고 물건을 선생님께 건네요.
3. 관리 화면 → **학생 등록** 탭에서 확인하고 **확인 · 공개**를 누르면 학생 화면에 올라가요. (설정에서 "선생님 확인 후 공개"를 끄면 바로 공개)
4. **상점**(선택): 켜 두면 등록한 학생이 '상점 대상'으로 기록돼요. 학생 등록 → 상점 대상에서 골라 **상점 부여**를 누르면 부여일이 기록돼요.
5. QR이 밖으로 퍼지면 설정에서 **QR 새로 만들기** → 포스터를 다시 뽑으세요. 예전 QR은 바로 막혀요.

**엑셀 내려받기**: 설정 → 도구 → 엑셀 파일 내려받기. 시트 4개(물품 전체 · 학생 등록·상점 · 수령 신청 · 분실 신고)로 나뉘고, 등록한 학생의 학번·이름·상점 부여 여부까지 들어 있어요.

**휴대폰 앱처럼 쓰기**
- 휴대폰으로 사이트를 열면 "홈 화면에 앱으로 추가" 배너가 떠요. 아이폰은 안내에 따라 공유 → 홈 화면에 추가, 안드로이드는 [추가] 한 번이면 돼요.
- 홈 화면 아이콘으로 열면 주소창 없이 전체 화면 앱처럼 열려요.
- 목록을 아래로 당기면 새로고침, 상세 창은 아래로 밀면 닫혀요.
- 인터넷이 약해도 한 번 본 화면과 사진은 빠르게 열려요. (귀중품 사진은 기기에 저장하지 않아요)
- 관리 화면은 휴대폰에서 아래쪽 탭(등록·물품·수령 신청·분실 신고·더보기)으로 움직여요.
- 상세 화면의 "친구에게 알려주기"로 카카오톡 등에 링크를 보낼 수 있어요.

### 개인정보 보호
- **귀중품**(지갑·카드는 기본으로 켜짐): 학생에게 사진이 보이지 않고 글로만 공개됩니다. 수령할 때 내용물을 물어 본인을 확인하세요.
- **모자이크**: 휴대폰에서 모자이크한 사진만 서버에 저장되므로 원본은 남지 않습니다.
- **입장 코드**: 교내 게시물로만 안내하세요. 코드가 밖으로 퍼지면 설정 → 학생 입장 코드에서 바꾸고 "기존 학생 모두 로그아웃"을 켜세요.

## 자주 하는 작업

| 하고 싶은 일 | 방법 |
|---|---|
| 담당 부서 이름(학생부, 생활안전부 등)·입장 코드·관리자 비밀번호·학교 이름·보관 기한·장소 변경 | 관리 화면 → **설정** |
| 화면이나 기능 업데이트 반영 | 새 파일을 덮어쓴 뒤 `npm run deploy` |
| 품목·색상 목록 변경 | `src/config.js` 수정 후 `npm run deploy` |
| 데이터 백업 | 설정 → 엑셀로 내보내기, 또는 `npx wrangler d1 export lost-and-found --remote --output=backup.sql` |

## (고급) 학교 구글 계정 로그인으로 바꾸기

입장 코드 대신 학교 구글 계정으로만 들어오게 할 수 있습니다.

1. Google Cloud Console에서 OAuth 클라이언트 ID를 만듭니다.
   - 동의 화면 유형: **내부**
   - 클라이언트 유형: **웹 애플리케이션**
   - 승인된 JavaScript 원본: 사이트 주소
2. `wrangler.jsonc`를 다음과 같이 고칩니다.
   - `AUTH_MODE`를 `"google"`로 변경
   - `GOOGLE_CLIENT_ID`, `ALLOWED_DOMAINS`, `ADMIN_EMAILS` 입력
3. `npm run setup`을 다시 실행합니다.

## 폴더 구조
```
setup.mjs        자동 설치 스크립트
wrangler.jsonc   Cloudflare 설정(학교 정보, 로그인 방식, 보관 기한)
schema.sql       데이터베이스 테이블
src/             서버 코드 (index: API, auth: 로그인, ai: 사진 자동 태깅, config: 목록)
public/          화면 (index: 학생, admin: 학생부, today: TV 화면, poster: QR 포스터, login)
                 icons.js: 아이콘(Lucide, ISC), vendor/qrcode.js: QR 생성기(MIT)
```
